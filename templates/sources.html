Data Sources

Information about the data sources used in this project

Open-Meteo Air Quality API

Endpoint: https://air-quality-api.open-meteo.com/v1/air-quality

Authentication: None required (non-commercial use)

Data Type: CAMS atmospheric-model output

Resolution: 11 km over Europe, 45 km globally

Coverage: Worldwide coordinates

Pollutants: PM2.5, PM10, CO, NO2, SO2, O3

Documentation: open-meteo.com

⚠️ Important: This data is a modeled estimate, not a physical ground-sensor reading. It is real, non-fabricated data but must be labeled honestly in the UI.

OpenAQ (Optional Secondary Source)

Endpoint: https://api.openaq.org/v3

Authentication: Free API key required (X-API-Key header)

Data Type: Physical ground-station measurements

Coverage: Inconsistent in India outside major metros

Registration: explore.openaq.org/register

ℹ️ This is a stretch-goal enhancement. The project is fully functional using Open-Meteo alone.

Kaggle Historical Dataset

Purpose: Training machine learning models

Placement: Place the CSV file in the data/ directory

Format: CSV with columns for date, city, and pollutant concentrations

Mapping: Column names are auto-detected and can be configured

AI Provider (Optional)

Default: Google Gemini API (free tier, no credit card required)

Key Location: .env file (never exposed to frontend)

Get a key: aistudio.google.com
