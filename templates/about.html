About This Project

Air Quality Monitoring and Prediction Dashboard

Project Overview

This is an intermediate-level college mini-project that demonstrates a full-stack web application for monitoring and predicting air quality. The system retrieves real air-quality data from the Open-Meteo API, stores it locally in SQLite, analyzes historical trends, and uses machine learning to predict future PM2.5 levels.

Key Features

  • 🌍 Real-time air quality monitoring using Open-Meteo API
  • 📍 Browser geolocation for automatic location detection
  • 🔎 City search for manual location selection
  • 📊 Historical data analysis with interactive Plotly charts
  • 🤖 Machine learning predictions (Linear Regression & Random Forest)
  • 📈 Model evaluation with MAE, RMSE, and R² metrics
  • 💾 Offline-first architecture with SQLite caching
  • 🔄 Data synchronization with graceful fallback
  • 💬 Optional AI-powered explanations
  • 📥 CSV data export

Technology Stack

Backend: Python, Flask
Frontend: HTML5, CSS3, JavaScript
Data: Pandas, NumPy
ML: Scikit-learn
Visualization: Plotly.js
Database: SQLite
API: Open-Meteo Air Quality API
AI: Google Gemini API (optional)

Important Notes

⚠️ Data provenance: Open-Meteo data is CAMS atmospheric-model output — a modeled estimate, not a physical ground-sensor reading. It is real, non-fabricated data but must be labeled honestly.

⚠️ AQI calculation: The Indian AQI is computed using CPCB methodology — the maximum of individual pollutant sub-indices, not an average.

⚠️ ML predictions: Predictions are educational estimates, not official forecasts.

⚠️ AI responses: AI-generated information is for general awareness and does not replace professional medical advice.

Academic Context

This project demonstrates: web development, REST API integration, offline-first architecture, database management, data preprocessing, exploratory data analysis, data visualization, machine learning, model evaluation, AI API integration, browser geolocation, and error handling.
